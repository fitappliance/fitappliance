LG Washing Machine dimensions and clearance requirements

LG washing machine installs are easier to shortlist when cabinet space and service room are checked together. Use these figures as the first pass before you compare exact models. Current guide figures are 20mm at each side, 50mm at the rear and 50mm above. The side gap is 10mm wider than the usual category baseline. The rear allowance is 50mm tighter than the default figure. The top allowance is 40mm taller than the default figure.

Installation Tips

  • Measure with the water taps and waste hose in mind, not just the cabinet box.
  • Leave room for the hoses to curve naturally so the machine can sit square once it is levelled.
  • If the laundry door swings inward, measure that arc before the machine is delivered.
